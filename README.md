# 🚀 CI/CD Demo App (Full-Stack Project)

A full-stack web application built to demonstrate modern software development practices including CI/CD concepts, API development and cloud database integration.

---

## 📖 Project Overview

This project is a simple item management system where users can:

- Add items with a name and description
- View all added items
- Store data persistently in a cloud database

It is built to simulate a real-world production workflow with frontend, backend and database integration.

---

## 🛠️ Tech Stack

### Frontend
- React.js
- JavaScript
- HTML / CSS

### Backend
- Node.js
- Express.js
- REST API

### Database
- MongoDB Atlas

### Tools & Concepts
- GitHub Actions (CI/CD concept)
- Git version control
- RESTful APIs
- Environment variables

---

##  Features

- ➕ Add new items
- 📄 View stored items
- 🔗 Frontend–Backend API integration
- ☁️ Cloud database storage (MongoDB Atlas)
- 🔄 CI/CD workflow structure (GitHub Actions ready)
